Core utilities

Tools to improve developer productivity

As part of the cloud platform team, I led design for the core vertical which includes the homepage, onboarding, and cloud management services.

Here is a brief overview of the work I did. If you would like more in-depth case studies, please feel free to contact visudha96@gmail.com

Application and environment management

Redesigned the experience to manage remote development environment and application instances to better support new users and increase developer productivity. This includes lifecycle management functionalities like create, read, update, and delete.

Tutorials

To improve the onboarding experience on to the C3 platform, I designed the visionary experience for tutorials that helped get buy in from several cross-functional teams. Tutorials walk users through the process of building or extending simple applications, and showcase best-practice examples of code and development workflows along the way.

Integrated development experience

One of the key experiences we offer developers is the C3 VS Code Extension that enables them to interface with the C3 platform without exiting their native tool. I designed the landing page and tester features for the extension by leveraging user inputs and telemetry.
